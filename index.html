How it works (privacy)
  • Images are selected from your computer using the file picker or by dropping onto the grid.
  • They are displayed via URL.createObjectURL (local blob: URLs). No uploads.
  • Replacing/clearing cells revokes old object URLs to free memory.
  • Export renders the visible grid into an in-memory canvas and saves a PNG locally.
Runs completely local — no network calls.
